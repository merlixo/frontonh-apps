# Frontonh Apps

Pages publiques, politiques de confidentialité et téléchargements de mes
applications, servis par GitHub Pages : <https://merlixo.github.io/frontonh-apps/>.
Le code source des apps n'est pas public.

## Organisation

Un dossier par app, à l'URL `https://merlixo.github.io/frontonh-apps/<app>/` :

- `<app>/index.html` — page de l'app (lien de la fiche Play Store) ;
- `<app>/privacy/index.html` — politique de confidentialité (URL déclarée
  sur Google Play, ne jamais la déplacer).

Releases : tags préfixés par l'app, par ex. `glisspad-companion-v1.0`. La
page de l'app pointe vers le fichier de la dernière version (« latest » est
partagé entre toutes les apps de ce dépôt).
